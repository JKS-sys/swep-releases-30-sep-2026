# Swep 0.2.13 — 16-oct-2026

- Much faster scans and a much faster sp. The cleaning runtime called `timeout` hundreds of times per scan, and macOS has none, so every one of those calls started Perl first — that is what made Clean, Uninstall's app list, Optimize and every `sp` command take so long. Swep and sp now answer as `timeout` (and as `du`, with a parallel walker) themselves. Folder sizes everywhere come from one new walker that reads a folder's kinds straight from the listing, uses every core only for big folders and sleeps instead of polling; scans run on the fast cores (they were on the efficiency cores); the built-in rules, developer leftovers and `sp clean`'s two halves run side by side; app signatures are remembered between runs (no `codesign` per app each time) and binary Info.plists are read without starting plutil; `sp disk` and the menu's disk view measure all folders in one walk; the menu no longer starts `tput` for every key press.
- Fixed: switching tabs quickly stopped the Pour page (and Notifications, Similar Pictures, cloud duplicates, phone storage, contact checks) from ever finishing — what they found while you were away was thrown away and the look started again. Those answers are kept now, looks still on their way are never dropped when something changes elsewhere, and finishing a clean no longer stops every other page's scan.
- Fixed: Swep's data never reached the admin dashboard. Swep's Worker sent it with a plain fetch to another Worker on the same domain, which Cloudflare never delivers (error 1042); it now goes through a service binding. "Connected" is shown only when the data really arrived (not just the hello), with the reason otherwise.
- Always connected: "Sync Now" is gone from the Owner Panel. Every copy of Swep reports in (anonymously: version, system, plan) a few seconds after start-up and every hour, to the dashboard and to Swep's Worker; the owner's Mac syncs hourly and retries ten minutes after a failure; the Worker pushes hourly.
- Fixed: turning the Dock or menu-bar icon off and on from the menu-bar or Dock menu crashed Swep — the icon was removed while macOS was still inside that menu's click. The change now waits until the menu has closed, only the last of several quick changes is applied, and the Dock presence is only changed when it really changes.
- More menus: Quick Actions (Quick Clean, Free Up Memory, Reclaim Purgeable Space, AI Clean, Leftovers, Languages, Plug-ins, Look Again Everywhere, Stop Everything, Crash Reports) and Selection in the menu-bar and Dock menus; Text Size, Show or Hide the Sidebar, Full Disk Access, YouTube and email in Appearance and Window and Help; a right-click menu on the quick panel, which also has Purgeable, Languages and Empty Folders now; four more Finder actions (Find Installer Files, Find Build Artifacts, Find Plug-ins, Find Tiny Junk Files — sixteen in all); on a row: Move to the Trash, Path for Terminal, What is this? (searches the web); anywhere: Quick Actions, Text Size, sidebar, Check for Updates, Reload.
- New log box everywhere: a window-style frame that glows in the colour of its state, a progress strip while lines arrive, elapsed time, line count, filter chips (All · Steps · Done · Warnings · Problems), search, follow-the-end with a "Latest" button, Wrap, Copy, Save as a text file, Expand and Fold.
- Language Files: also printer drivers, settings panes, screen savers, input methods, Quick Look and Spotlight plug-ins, services, camera drivers, Audio Unit/VST/VST3/CLAP plug-ins and vendors' helper apps — each signed again afterwards, one password for the ones that belong to the administrator.
- More junk: debug-symbol bundles, heap snapshots and profiles, FUSE/NFS leftovers, Windows recycle bins and FOUND.000 fragments on external disks, external disks' own Trash, Mac OS 9 desktop files, Windows Media Player album art, phone thumbnail folders, Picasa files, Adobe lock files, more package-manager logs, Linux core dumps, Java replay logs, TypeScript build records, Python coverage data, old tox/nox environments, Dart/Flutter/Angular caches, SWC/Vite/Jest caches, Google Drive temporary folders, Dropbox's cache, old .bak files (for review).
- More caches: Brave, Arc, Vivaldi, Opera, Discord, Notion, Obsidian, Postman, Cursor, Windsurf, Zed, Adobe media caches, Steam, old Xcode device-support files, simulator caches, Mail attachments you opened, Unity Asset Store downloads.
- Fixed two dangerous rules: "Sandboxed app caches" listed whole app containers (their data) once Full Disk Access was on — it now takes only each container's Caches folder; "Docker build cache" pointed at Docker's disk image (every image and volume) — it now takes only Docker Desktop's logs.
- More leftovers: caches in macOS's per-user folder (/var/folders/…/C) of removed apps; home folders of removed Continue, Codeium, Trae, Kiro, Void, Positron, RStudio, Rancher Desktop, Parallels, Eclipse, NetBeans, Figma, Insomnia, MongoDB Compass, SQL Developer, DBeaver, Spotify (spicetify), Steam, Minecraft, Signal and more.
- More plug-ins: MIDI drivers, switched-off plug-in folders, third-party speech voices, Adobe CEP panels and UXP data, Motion templates, printer drivers, file-system plug-ins (NTFS, FUSE), third-party kernel extensions, PDF workflows, dictionaries and spelling dictionaries, Atom/Kiro/Trae/Void/Positron/Zed extensions.
- Twelve new sounds, each with its own self-drawing picture: letters flying out (languages removed), a droplet (purgeable space), a floppy disk (log saved), a magnifier (text size and log search), a sidebar, a refresh cycle (look again), a stop sign, a sieve (new kinds of junk found), an antenna (dashboard connected), a chip (kernel extensions and file systems removed) and a printer (drivers removed).
- More colour (still no pink, now checked by hue too): two new hues (rust and mustard), brackets in six colours by depth, file extensions, numbers, sizes, percentages, paths, quoted words, keys, times and status words tinted inside notes, dialogs, cards, toasts and tabs; dialog titles in a gradient.
- New graphics: an aurora and orbiting dots in each page's own colours behind its title; floating sparks on "all tidy" screens.
- Smaller download: the bundled cleaning runtime is packed with xz (about a quarter smaller).

- Fixed: the release stopped silently right after "5 build(s), 2 at a time". The build board looked up a log that was still empty, and under the script's strict mode an empty lookup ended everything without a word. Every lookup on the board now tolerates an empty log, and if anything ever stops update.sh unexpectedly it now prints the line and command where it stopped.
- Fixed: turning the Dock or menu-bar icon off and on could crash Swep or leave a dead icon behind. The menu-bar icon is now removed by its id and made only when none exists; the change runs on the main thread, any panic in there is caught and written to the log, and coming back to the Dock puts the chosen app icon and the window back.
- New: the menu-bar icon's left click opens a quick panel — free space as a ring, what Swep has freed, and twelve one-click actions (Clean Now, AI Clean, Free Memory, Leftovers, Large Files, Duplicates, Uninstall, Pour, Plug-ins, Repair, Status, Settings). Double click opens the window; Esc or clicking elsewhere hides the panel.
- New: a much bigger right-click menu on the menu-bar icon and the Dock icon — free space at the top, Open, Quick Panel, Clean Now, AI Clean, Free Memory, then Clean, Apps and Plug-ins, System, Devices, Appearance (theme, sounds, animations), Swep Lives In (switch between Dock and menu bar right there) and Window and Help (show, hide, compact, large, centre, shortcuts, updates, about, website, star on GitHub, log folder), Settings, Pro, Account and the Owner Panel.
- New Finder right-click actions: Find Small Junk Here, Remove Unused Languages (on an app), Find Leftovers of This App, and Delete Immediately (skips the Trash, asks first) — twelve in all.
- Right-click inside Swep: on a row — Open, Quick Look, Get Info, Open a Terminal here, Copy (path, name, folder, size, the row); on a group — copy the group, or remove the whole group; anywhere — Layout, Appearance, Window, Swep Lives In and Settings.
- Log boxes everywhere: crash reports, search results and command output in dialogs are shown in the same log box (coloured by kind, Copy and Expand).
- Leftovers: home dot-folders that apps leave behind (~/.vscode, ~/.cursor, ~/.windsurf, ~/.zoomus, ~/.android, ~/.orbstack, ~/.lmstudio, ~/.atom, ~/.zed, ~/.arduino15 and more) once the app is gone, plus folders named after removed apps in ~/.config, ~/.local/share and Sentry's crash cache (the desktop's own folders are never touched).
- Plug-ins: editor extensions (VS Code, VS Code Insiders, VSCodium, Cursor, Windsurf, Sublime Text) with older copies of updated extensions marked, keyboard layouts and alert sounds.
- AI Clean: Xcode test results (.xcresult) older than two weeks, crash reports saved as files (.crash, .ips) and TypeScript build records.
- Language Files: spelling dictionaries inside apps (dictionaries, hunspell; .dic, .aff, .bdic).
- Five new sounds with their own pictures: the Dock and menu bar switching, Quick Look, Get Info, a background service found among the leftovers, and editor extensions removed.
- More colour: sidebar headings, every settings row, dialog titles, key lists and menu headings each take their own hue (no pink).

On macOS, if the app is reported as damaged, run: `xattr -cr /Applications/Swep.app`
